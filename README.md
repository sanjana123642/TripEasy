# TripEasy – Travel Booking System

TripEasy is a Travel Booking System backend developed using Node.js, Express.js, MongoDB, Firebase, JWT, and Socket.io.

## Features

- User registration and login
- JWT-based authentication
- Browse and search trips
- Book trips
- Create and view itineraries
- Agent management
- Firebase notifications
- Real-time availability updates using Socket.io

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- Firebase
- JWT
- Socket.io

## API Modules

- Authentication
- Trips
- Bookings
- Itineraries
- Agents
- Notifications

## How to Run

1. Clone the repository

```bash
git clone <your-github-repository-url>
Open the project folder
cd TripEasy
Install dependencies
npm install
Create a .env file and add your MongoDB, JWT, and Firebase credentials.
Start the server
npm start

The backend will run on:

http://localhost:3000
